def calculate_purchase_date(current_year, current_month, pet_age_years, pet_age_months):
    total_months = pet_age_years * 12 + pet_age_months
    purchase_year = current_year
    purchase_month = current_month - total_months
    
    while purchase_month <= 0:
        purchase_month += 12
        purchase_year -= 1
    
    return purchase_year, purchase_month

🐛 Проблемы и их решение
Проблема 1: Некорректный расчет даты при вводе возраста в месяцах
Проблема: При вводе "5 месяцев" программа вычисляла дату покупки как ноябрь 2025 года вместо апреля 2026 года.

Причина: Функция возвращала возраст в годах (0.42), что приводило к ошибкам округления.

Решение: Изменение логики функции для возврата кортежа (годы, месяцы) и корректной обработки месяцев.

Проблема 2: Ошибка при вводе текста вместо числа
Проблема: Программа выдавала ошибку ValueError при вводе "5 месяцев".

Решение: Добавление обработки текстового ввода с использованием регулярных выражений для извлечения чисел.

Проблема 3: Пустые строки в полях имени и города
Решение: Добавление циклов проверки с методом strip() для удаления пробелов и проверки на пустоту.
